🌕 เกี่ยวกับลอยกระทงออนไลน์

โครงงานพัฒนาเว็บแอปพลิเคชัน & Deploy สู่ GitHub Pages

เว็บลอยกระทงออนไลน์นี้สร้างขึ้นเพื่อสืบสานประเพณีไทยอันดีงาม ส่งเสริมการขอขมาพระแม่คงคา โดยร่วมรณรงค์ลดขยะในแม่น้ำลำคลองผ่านระบบออนไลน์ 100%

✨ ฟีเจอร์เด่น:

  • เลือกแบบกระทงได้ 5 สไตล์ (ใบตอง, ดอกบัว, กะลา, ขนมปัง, และดอกไม้หลากสี)
  • กรอกชื่อและเขียนคำอธิษฐานส่วนตัว พร้อมเลือกข้อความมงคลด่วน
  • กระทงลอยตามสายน้ำแบบ Real-time พร้อมแสงเทียนกระพริบไหว
  • คลิกกระทงในแม่น้ำเพื่ออ่านคำอธิษฐานและกดส่งหัวใจให้กันได้
  • คลิกบนท้องฟ้าเพื่อจุดพลุดอกไม้ไฟหลากสีสัน
  • เสียงดนตรีไทยสังเคราะห์ด้วย Web Audio API (ไม่ต้องพึ่งไฟล์เน็ต)
  • สร้างและดาวน์โหลดบัตรที่ระลึกการลอยกระทงเป็นไฟล์ภาพ
💡 เทคโนโลยีที่ใช้: HTML5, CSS3 Glassmorphism, JavaScript ES Modules, Canvas 2D, Web Audio API, Node.js HTTP Server, Vite, และ GitHub Pages CI/CD Action
